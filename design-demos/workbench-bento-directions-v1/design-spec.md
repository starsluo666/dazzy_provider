# 达人端首页重设计方向稿：设计规格

## 1. 任务范围与不变项

本轮只重新定义达人端“首页 / 工作台”的视觉表达，不改变业务结构、信息顺序、字段含义、交互入口或状态逻辑。页面仍按当前生产结构组织：顶部达人身份信息 → 在线接单状态 → 本月经营数据 → 下一单 → 待处理事项 → 悬浮报警入口 → 底部三栏导航。实名认证、资料完整度、定位状态、在线开关、月收入/月订单/服务时长、近七日趋势、下一单详情、订单跳转、消息数量与底部导航都必须保留。方向稿以“已认证、资料已完成、在线接单中、有下一单”的常态为主视觉状态，异常、离线、无订单等状态在正式实施时沿用既有逻辑，不在方向选择稿中虚构新的业务分支。

## 2. 设计目标

参考图真正值得吸收的不是 NFT 或日程产品的题材，而是三种共同的界面品质：模块像桌面卡片一样清晰分区；卡片之间有尺寸和权重差异，不再平均用力；大面积留白配合克制阴影，使信息密集但不拥挤；重点动作使用少量高饱和色，普通信息退回白色与浅灰；小组件内部具有独立视觉节奏。首页需要在 393×852 的 iPhone 逻辑尺寸内形成完整、稳定的一屏印象，首屏应同时看到在线状态、经营核心指标和下一单主要信息。页面允许轻微滚动以适配小屏，但不能通过缩小字号或压缩点击区域来硬塞内容。主要正文不小于 13px，核心数字 22–30px，按钮与开关的有效触控高度不少于 44px。

## 3. 视觉与层级规则

品牌色继续使用 DAZZY 青色体系，主色为 #11C1C4，深色为 #08A9B1；橙色只用于提醒或时间节点；蓝色只用于辅助维度。页面基底使用冷白或极浅青灰，不做满屏高饱和渐变。卡片圆角控制在 18–24px，主要模块可有轻量边框、内高光和两级阴影，但不能每张卡都同时堆叠强阴影。文字使用系统无衬线字体，标题黑色且字重明确，说明文字使用 #667085 附近的灰蓝色。所有状态颜色都必须同时配合文字、图标或形态，不只依赖颜色。

## 4. 三个方向的差异

方向一“活力积木”来自参考图的多色卡片和设计风格轮盘抽中的 Friendly Geometric Candy：它用青、橙、蓝三块任务卡形成强记忆点，卡片底部有轻微实体投影，按钮按下会短距离下沉，但整体保持成人服务工作台的克制感。方向二“清晰任务板”以优秀任务管理产品的安静秩序为现实参考：大量白色、细分隔线、单一青色强调，经营数据和下一单更像可快速扫描的任务摘要。方向三“轻盈展台”采用 Apple 式物理层级与参考图的漂浮画廊构图：非对称卡片、半透明材质、柔和环境光和更明显的空间深度，突出在线开关与下一单操作。

## 5. 交互与动效

在线开关必须有明确开/关反馈；按钮按压只做 1–2px 位移与阴影收缩，避免大幅缩放。底部导航保留首页、订单、我的三项，当前页状态清晰。悬浮报警按钮固定于内容右下区域但不遮挡下一单按钮或底栏。方向稿提供基本点击反馈用于验证层级；正式落地时不新增 API、路由或状态字段。尊重减少动态效果设置，不使用持续漂浮、闪烁或循环装饰动画。

## 6. 素材与技术假设

该页面是数据型工作台，新图片不是表达核心，因此本轮不生成新的内容图片。现有“下一单”背包插画可在最终实现中继续使用；方向稿用代码原生图形和符号表达信息，避免引入不稳定网络素材。三个方向均使用技能提供的 iPhone 15 Pro 393×852 设备框架，保证对比基准一致。方向稿仅用于选择视觉语言，选定后再把对应设计映射回 `src/pages/workbench/index.vue`，完整保留 Vue/uni-app 业务代码。
