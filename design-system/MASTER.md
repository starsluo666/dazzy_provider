# DAZZY 达人端设计基线

- 页面背景：纯白到极浅青色 `#F7FBFB`，不可替换成米色或暖灰。
- 品牌主色：`#11C1C4`；深色强调：`#08A9B1`；柔和底色：`#DDF8F7`。
- 文本：主文字 `#111827`，次文字 `#667085`，弱文字 `#98A2B3`。
- 语义色：预约时间 `#FF5A1F`；紧急求助 `#FF3E46`；在线 `#20B86C`。
- 卡片：白底，圆角 20–24px，细边框与低强度青灰阴影。
- 间距：4/8pt 体系，页面水平边距 16px；触控区域至少 44pt。
- 首页层级：身份 → 在线接单主状态 → 本月经营（三项同排 + 周趋势）→ 下一单 → 一键报警 → 待处理 → 三项底部导航。
- 图标：统一圆角线性矢量风格，2px 描边；禁止 Emoji 作为结构图标。
- 动效：按压 80–150ms，页面微动效 150–300ms，并尊重 reduced-motion。
